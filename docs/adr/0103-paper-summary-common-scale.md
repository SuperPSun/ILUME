# ADR-0103：独立论文汇总与共同训练集尺度

- 状态：已接受
- 日期：2026-10-23
- 范围：新的论文比较入口；训练、评估及原有统一汇总合同保持原样。

## 背景

ADR-0031允许实验汇总混合模型各自的训练目标scaler。AIonopedia的样本标准差、
MoLFormer保留训练行的标准差与完整训练集总体标准差可能不同。论文需要在同一
数据尺度上比较原单位预测，同时完整展示任务优势与不足。

## 决定

1. 新增`scripts/benchmarks/summarize_paper.py`，显式接收Stage3配置、一个ILUME
   运行根和十模型基线根。当前只接受`catalog_v4_3407`配套数据；不搜索最优ILUME，
   不复用历史split42、HPO候选或不同study的折。
2. 默认要求注册表全部实验任务、ILUME五个`three_phase_final`验证折及十个完整基线。
   `--with-test`额外要求同一ILUME study的完整测试集成，只比较实际有非空测试数据的
   任务。hydration保留random/cv1与无测试集事实。
3. 从完整预测重新计算原单位MAE、RMSE和R²。按任务、按折，使用另外四折完整
   训练集目标的总体标准差（`ddof=0`，精确零方差取1）作为所有模型的共同尺度。
   先五折等权，再实验任务等权，得到论文的总体归一化MAE。不使用模型自己的
   `normalized_mae`，也不聚合不同单位的原始MAE作为总体分数。
4. 测试集先核对五折原单位预测均值，再计分；兼容现有FP32或FP64平均的数值精度。
   共同归一化尺度取五折训练集总体标准差的算术平均。验证和测试分别报告。
5. 逐任务排名、平均名次、第一/前三数量、相对最强基线增益及性能覆盖曲线均采用
   五折平均原单位MAE（测试为集成MAE）。并列使用competition rank。最强基线是
   逐任务十模型的最优结果集合；完整保留负增益。性能覆盖曲线使用全部任务与
   全部有限误差比，不选择有利区间；最优MAE为0且自身误差非0的比值为无穷，CSV
   中为空，始终不计入有限阈值覆盖；基线MAE为0时相对增益未定义。
6. 复用现有报告发现及语义身份校验，额外核对当前源文件SHA、预测清单SHA、完整
   行集合及顺序、分子身份、条件、目标、评估折与五模型集成。元数据声明检查点
   来源时，核对检查点清单SHA。该入口不重新加载权重或对全部权重文件重新计算SHA；
   完整模型回传审计仍按v4手册执行。
7. 以独立`reporting.paper-comparison.v1`绑定共同尺度、数据比较身份、明确选择的
   ILUME及所有输入元数据/summary指纹。保存原评估身份和原始归一化信息；不改写
   原训练身份、预测、ADR-0031旧榜单或已有报告。
8. 仅在新的输出目录原子发布CSV、中文overview、JSON及SVG/PDF。目标存在则拒绝，
   输入损坏或绘图失败不留下半成品，也不替换历史报告。

## 解释边界

- 明示3407是验证选出的划分；五折标准差只表示折间变化，不生成显著性或独立重复
  训练结论。完整跨划分信息见[HPO结果](../hpo-results.md)。
- 不自动按任务大小重分组、挑选优胜任务或改变权重；分组与顺序来自显式配置注册表。
- 实验图表不混入模拟结果。三模拟与共同热膨胀继续使用现有独立榜单；HOMO/LUMO不
  构成ILUME比较。消融、条件趋势与计算成本需要各自配套证据，本入口不推断。
- 验证散点使用五个留出折的全部样本；其样本合并误差不等于五折等权MAE。

运行命令与输出说明见[论文汇总手册](../paper-summary-runbook.md)。
