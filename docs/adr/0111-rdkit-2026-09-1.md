# ADR-0111：ILUME 主线固定 RDKit 2026.9.1

## 状态

已接受（2026-10-31）。仅升级主项目RDKit运行时依赖，不改变Stage1架构、监督定义、维度、Stage2/3训练配方或baseline独立环境。版本隔离替代“复用2025.09.5产物”的运行前提，不改写历史产物。

## 决定

- `pyproject.toml`从宽泛的 `rdkit>=2024.3` 改为 `rdkit==2026.9.1`；Python导入运行时应为 `2026.09.1`。独立teacher环境同样采用该版本，保留其NumPy1.26.4与Uni-Mol包配方。主环境与teacher环境都检查安装元数据及导入运行时，不只依赖pip/conda显示值。
- 隔离wheel验证确认：2026.09.1的默认 `Descriptors._descList` 仍为217项，名称/顺序与历史2025.09.5准备清单一致。learned1024、atom512、217维监督和1241维实体接口不变。不增加新描述符，不自动应用ADR-0110筛选；不启用beta ETKDGv4或其他新可选机制。
- 同维数不承诺化学解析、canonical、环/图、描述符、原子映射或构象数值相同。沿用原有严格 `feature_generation_contract`、corpus/teacher来源和SHA检查；版本已进入身份，无需仅为此次升级增加artifact格式或放宽加载。
- 2025.09.5及其他版本的已有prepare、统计、teacher、电荷sidecar与checkpoint保持历史只读；在匹配历史Git与依赖环境中使用。新版本重新prepare Stage1/sidecar/teacher，重训Stage1，继而重新prepare/train/evaluate Stage2/3。原始数据与split authority、Uni-Mol源权重可复用；不自动启动正式运行、不自动迁移缓存。
- 已有主线/候选YAML的预算和来源路径不批量改写。主线保留三个Stage的 `configs/v4/stage*/base.yaml` 入口及配对的 `outputs/v4/stage*/base/` 来源，不保留临时版本后缀Base配置。复用标准路径须先按用户明确确认的清单清理或归档旧运行目录；仅删权重不足以清空旧metadata/log及不兼容sidecar。也可由用户选择独立新输出并同步全部来源引用。旧来源仍被严格拒绝，不以修改metadata、SHA或回退版本掩盖差异。
- 主环境继续命名为 `ilume`；确认没有RDKit使用进程、备份旧包后，仅清理旧RDKit的pip/conda安装并安装固定新版，不删除整个环境，不更改Python、PyTorch/CUDA或NumPy。禁止直接覆盖混装旧包而保留冲突元数据。baseline的独立环境、hash lock及其预训练模型合同保持原样；teacher环境单独维护，历史复现使用匹配历史Git的独立依赖环境。该依赖升级不意味着已验证预测性能提升。

## 验证

使用临时隔离2026.9.1 wheel运行测试，核对包版本、runtime、217维清单、有机/带电/单原子图、训练与导出接口，以及旧版本特征合同拒绝。小数据prepare/teacher测试不生成正式缓存。记录完整测试中的既有缺失资源失败，不修改或补造历史配置。正式Uni-Mol GPU前向仍须用户先执行手册的小样本审计，不以RDKit smoke测试替代。

官方版本来源：[PyPI](https://pypi.org/project/rdkit/2026.9.1/)、[RDKit发布说明](https://github.com/rdkit/rdkit/releases/tag/Release_2026_09_1)。执行及新目录配对见 [v4手册](../v4-runbook.md#rdkit-202691-主线升级)。
