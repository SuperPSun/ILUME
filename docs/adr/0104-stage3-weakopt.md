# ADR-0104：固定架构的 Stage3 WeakOpt 参数优化

- 状态：已接受
- 日期：2026-10-25
- 范围：独立 WeakOpt 研究；正式配置和历史产物保持原身份。

## 决定

固定 `optimized_3407` 的数据、完整24实验/两模拟、分组、全部宽度和专家数量、Stage1/Stage2来源、共享梯度及三阶段算法。只允许现有实验任务的 PRIVATE 学习率、三阶段轮数和 `model_overrides.private_dropout` 改变。每个候选先冻结为完整YAML，再从相同Stage2权重训练完整Stage3；不拼接不同候选的任务权重，不跨配置恢复。

配置位于 `configs/HPO/WeakOpt`，新增产物位于 `outputs/HPO/WeakOpt`。参考配置、准备元数据、Stage1/2权重及独立论文验证汇总的原始来源SHA冻结；现有准备产物只读复用，不执行prepare。候选编号连续，仅追加，内容及语义去重，总上限80。首批24份以任务局部单变量为主；后续由研究者或用户授权的Goal分析验证结果、明确追加静态候选，不使用Optuna或自动采样。

## 选择与目标

使用验证集原单位MAE，先平均所选折，再逐任务与十个现役baseline比较；相同MAE计并列第一。选择顺序为第一名任务数降序、共同尺度nMAE升序、候选编号升序；允许总体误差变大，完整报告所有任务收益与退化。两折初筛只与同两折baseline比较，不算五折达标。共同尺度与ADR-0103一致。

目标是24实验五折验证至少15项第一，10项测试五模型集成至少6项第一，不能保证达到。先运行Fold1/3，入围者继续补Fold2/4/5。折selector不进入候选身份；原生恢复校验完成折后跳过，不重训。训练每轮验证只报告，仍发布预定末轮。测试不进入候选生成、报告或锁定；`finalize`要求五折完整并锁定验证排名最优候选，锁定后再进行一次正式测试比较。预算耗尽后如实报告未达标，不因测试结果返回搜索。

## 调度与兼容

独立 `scripts/HPO/weakopt.py` 复用现有HPO队列、子进程和独立验证接口；不改Stage源代码或其他HPO入口。只允许物理GPU2/3及其子集，每卡一作业、总并发不超过2；原生训练内部折并发1。GPU及候选锁仅写WeakOpt根，避免两个WeakOpt控制器争抢。失败现场保留，Ctrl+C只结束本控制器启动的子进程。

验证标记须匹配原生评估身份，检查标记全部文件SHA及预测完整性；缺折不进入完整排名。保存参考和候选完整权重、日志及恢复产物。新的报告写独立时间戳目录，锁定选择不覆盖。3407曾通过跨划分验证选择，且本轮使用现有验证反馈优化；不将其测试宣称为完全独立于此前探索的泛化估计。

运行见[WeakOpt手册](../weakopt-runbook.md)。小数据验证参数白名单、候选去重和80组上限、GPU限制、补折恢复、篡改和跨身份拒绝、并列及排名顺序；执行项目pytest和入口/编译/链接检查。
