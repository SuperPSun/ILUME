# ADR-0118：22任务数据协议下的 FLft baseline 定向补训

## 状态与范围

已接受（2026-11-07，用户确认3090优先、H100承接大显存作业，并要求提供命令）。本轮只补训数据发生变化的10项实验任务；不实施其余任务复用、不发布完整22任务论文比较，不启动正式训练。

## 数据与模型合同

- 新增十份自包含 `configs/benchmarks/FLftv4_3407/<model>.yaml`，协议为 `flft_v4_3407_22_retrain`。数据固定 `data/3407`，authority固定 `configs/v4/stage3/base.yaml`，必须解析为22项活跃实验任务，不允许平衡压力和水活度系数回流。
- 本轮显式任务为电导率、黏度、密度、表面张力、玻璃化转变温度、熔点、热分解温度、折射率、solvation和hydration。每模型五折，共50个训练作业；十模型合计500个，其中450个GPU作业、50个CPU作业。
- hydration继续单solute、温度、random/cv1、无测试集；其余任务沿用当前Base注册表的输入、目标和split。使用更新的solvation数据，不修改原始数据或SHA。
- 各模型的结构、预训练资产、环境锁、训练种子、精度、batch、梯度累积及训练配方与历史3407配置逐项一致；神经模型10轮、XGBoost 1000 trees，发布末轮，验证只报告。不将ILUME的211维描述符或DGT应用到独立baseline。
- MLP从头训练，ECFP-XGBoost使用固定指纹；FLft只是用户指定的十模型目录归类，不意味着这两个模型进行了预训练编码器微调。MLP/XGBoost使用主环境的现役RDKit，新特征缓存与旧缓存隔离，不宣称跨版本特征等价或旧产物可复用。
- 三模拟本轮禁用；其他12项实验和历史两项退出任务均不调度。完整22任务比较需要另行审计及组装，不能把本轮10任务macro冒充22任务结果。

## 身份、输出与调度

新协议进入registry及训练/评估身份；保持原检查点校验，不接受旧24任务权重或旧split42复用清单。完成状态跳过继续校验配置、数据来源、权重及预测清单；失败在新attempt完整重跑，不提供训练恢复。

2026-11-07用户按精确清单确认后，旧根 `outputs/benchmarks/v4_3407` 已整体改名为 `outputs/benchmarks/FLftv4_3407`，10项变化任务的旧训练/评估及完整旧sweep记录已归档至 `trash/outputs/benchmarks/FLftv4_3407-outdated-20261107`。旧文件字节、训练身份和历史报告不改写，迁移映射与核验记录保存在 `outputs/benchmarks/maintenance/20261107-FLftv4_3407/`。历史评估中原检查点路径不自动改写或放宽校验。

本轮新输出固定为 `outputs/benchmarks/FLftv4_3407/retrain_22/<model>/`，特征缓存使用 `retrain_22/cache/`，与保留的历史目录隔离。3090四卡优先运行除LlaSMol外的八个GPU模型；H100两卡运行LlaSMol及显存溢出任务；XGBoost单独CPU作业。每卡一个独立任务/折，不使用DDP，不改变batch或量化配方以迁就显存。szx本轮暂不安排。

两台机器不并发运行同一个模型的同一输出根；转移溢出模型前，先结束原sweep并将其完整输出迁至接收机器相同相对路径，经校验后再启动。所有完整权重、配置、日志、身份和预测最终回传4090。命令见[补训手册](../baseline-flft-22-retrain-runbook.md)。

## 验证

以临时小数据覆盖50折调度、十模型配方保留、22任务authority检查、退出任务拒绝、模拟禁用、跨协议身份拒绝及历史严格复用限制。执行项目完整pytest、入口帮助、编译、链接和diff检查；不执行正式训练/评估或资产下载。
