# ADR-0106：按完整请求训练的专用离子液体 GFlowNet

- 状态：已接受
- 日期：2026-10-26
- 替代范围：[ADR-0105](0105-universal-inverse-design.md) 的通用条件编码、随机任务训练、重标记、组合划分与部署合同。Stage1–3及冻结Predictor接口不变。

## 决定

每份生成模型只优化一个完整设计请求；该请求可以同时包含多个性质。性质组合、方向、阈值、权重、每项性质的工况和溶质、结构约束及是否固定阴离子均是固定训练合同。`configs/generation/*.yaml` 必须以完整内嵌 `request` 声明这些参数，不从运行时请求文件或缺省工况推断。现有示例数值仅说明格式，正式请求由用户填写。

删除性质embedding、Task/Context MLP、约束文本GRU及随机目标采样。前向策略只读取阴离子、当前/后继阳离子图及其交互和动作阶段标记；固定任务信息通过持续使用同一个奖励函数进入权重。阴离子条件化继续有效，与通用任务条件编码分开理解。独立图编码器沿用原宽度、深度和原子/键特征；`logZ` 简化为一个可训练标量。

完整轨迹采用普通 Trajectory Balance：`(logZ + ΣlogPF − ΣlogPB − logR)^2`。反向概率仍为合法父状态上的均匀概率，无可训练反向网络。阴离子自由选择或固定的模式在请求中锁定，生成与回放不切换模式。片段环境、可逆父状态、STOP、化学约束、多价单种阴阳离子及不展开计量的合同不变。

## 训练、协议与身份

在线轨迹和回放都只使用该请求，同请求轨迹可反复更新策略，但不再随机重标记性质、阈值、权重、工况或溶质。移除 `task_splits`、`training.task_mask`、`relabel_probability` 以及16组随机工况上下文。保留原固定预算、优化器、评分缓存、完整检查点及真实风险评分，不改奖励公式。

`prepare --kind protocol` 只读取所选性质的开发结构/工况参考，不读取正式测试标签；冻结请求、所选能力表和Predictor来源。新协议 `kind=ilume_dedicated_gfn_protocol_v1`、`format_version=2`。训练身份 `generation.dedicated-gfn.v1` 绑定完整请求、资源、协议、Predictor、模型、奖励、预算与种子。

新检查点 `kind=ilume_dedicated_gfn_v1`，张量hash命名空间 `generation.dedicated-model.v1`。完整保存模型、标量logZ、优化器、RNG、同请求回放、缓存、历史及执行身份。原通用检查点/协议明确拒绝加载，不转换身份或迁移旧优化器。周期产物不覆盖；同请求恢复读旧完整检查点、写新输出目录，并要求原执行身份。

## 采样与研究评价

采样和评估从同一配置的 `request` 读取已训练请求，不再提供 `--request` 或 `--partition`。改变任一科学字段时，旧协议先拒绝；准备新协议后，旧检查点身份仍须拒绝。运行时仅保留输出、设备、检查点/恢复选择以及已有随机/独立重组研究对照。改变候选数量或评分预算不改变所训练的请求。

候选阈值筛选、Pareto分层、结构多样性、原始样本和短缺报告保持不变。固定偏好得到的是该奖励分布中的候选及经验权衡，不宣称覆盖全部Pareto前沿或跨请求泛化。同一请求可由用户重复训练不同种子进行后续研究，但本次不增加自动实验调度或正式运行。

验证普通TB的目标分布、多路径和固定阴离子概率；同请求训练与逐位恢复；性质、方向、阈值、权重、工况、溶质、约束和阴离子选择变化的拒载；旧通用产物拒载；评分预算、失败记录、候选不足及CLI。执行项目全量pytest、入口help、编译和文档链接检查。正式资源准备、训练与研究评价仍由用户运行，见[生成手册](../generation-runbook.md)。
