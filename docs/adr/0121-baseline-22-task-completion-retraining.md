# ADR-0121：22任务 baseline 缺口全量补训

## 决定

已接受（2026-11-09）。全任务审计后，用户决定对缺口全部重训，包含原本可进一步审计等价性的无条件ILBERT任务，不执行等价派生。范围为MLP、ECFP-XGBoost及标准化ILBERT各63作业，共189作业；不重复执行已经完成的10项变化实验任务。

## 配置与数据

新增 `flft_v4_3407_22_completion` 协议，三份自包含配置位于 [completion](../../configs/benchmarks/FLftv4_3407/completion/)。显式固定其余12项实验任务、五折，以及热膨胀/HOMO/LUMO三项独立模拟。每模型12×5＋3＝63次训练，训练后执行验证及可用测试集评估。pEC50五折及HOMO/LUMO的ILBERT无条件旧身份也从头重训。

数据根为 `data/3407`，authority为 `configs/v4/stage3/base.yaml`；当前registry必须精确覆盖22项活跃任务，拒绝平衡压力、水活度系数和其他任务替换。实验使用当前注册表的条件、目标及split。热膨胀使用 `data/3407/stage2/thermal_expansion/`，HOMO/LUMO使用 `data/stage1/properties/{homo,lumo}/` 的原始train/valid/test，不构造3407子目录下的虚假电子数据路径。

MLP/XGBoost保持现役主环境RDKit2026.09.1及原特征定义，使用独立的新缓存；历史2025.09.5特征不跨版本复用。ILBERT沿用ADR-0119的训练行条件z-score，每任务/折分别保存统计量；无条件任务也保存对应空统计量。三模型结构、训练seed和资产不变，MLP/ILBERT10轮末轮发布，XGBoost1000 trees。验证只报告，不选检查点或学习率。新协议不能用于另外七个模型，也不改变原10任务协议。

## 输出与执行

输出固定为 `outputs/benchmarks/FLftv4_3407/completion_22/<model>/`，MLP/XGBoost特征缓存为 `completion_22/cache/features.sqlite3`。保留全部历史产物；新协议进入训练、评估、sweep及汇总身份，已完成任务跳过继续执行原严格完整性校验。旧协议不能占用新输出冒充已完成；失败使用新attempt完整重跑。

用户在3090启动：ILBERT使用GPU0/1、最多2作业；MLP使用GPU2/3、最多2作业；XGBoost单独CPU、最多1作业、每作业8线程。均为独立任务/折，不使用DDP，不更改batch或模型预算。GPU编号须在执行前确认空闲。入口、环境及预训练资源沿用现有安装，不新增下载或依赖。

操作命令见[补训手册](../baseline-flft-22-retrain-runbook.md#审计后剩余189作业补训)。交付阶段不提交Git、不启动训练或正式评估。所有完整权重、配置、身份、预测和日志最终回传4090同相对路径。

## 审计与报告边界

来源审计覆盖22实验×十模型及三模拟×十模型，共250任务组；旧版本差异与原身份保留。此次只落实189个缺口作业的独立训练入口，不自动复制审计通过的来源、不改写旧训练身份，也不修改论文汇总器。完整榜单仍需将已完成10任务、此处剩余任务及通过审计的历史来源按新比较身份组装。不得把本次12任务子集macro当作完整22任务结果。

## 验证

验证三配置与原配方一致、12项与原10项不重叠、三模拟来源路径、63独立训练作业、ILBERT标准化强制、错误任务/数据根/模拟集合拒绝、精确22任务registry及跨协议身份拒绝。只使用临时数据与现有调度测试，不启动正式训练；执行项目pytest、入口帮助、编译、Markdown链接及diff检查。
