# ADR-0123：完整22任务 baseline 来源组装与独立报告

## 决定

已接受（2026-11-10）。在ADR-0118的10项实验补训、ADR-0119的ILBERT条件标准化和ADR-0121的剩余189次补训完成后，新增独立完整baseline报告。现有训练、评估、通用汇总和论文比较入口保持原合同；本次不包含ILUME，不启动模型前向或训练，不改变任何训练身份、预测或历史报告。

2026-11-11修订：XGBoost的新报告来源按[ADR-0126](0126-xgboost-lightweight-variants.md)切换到500棵/深度4，不再回退1000棵。原版三个产物目录已按精确确认清单删除；已生成报告保留历史身份和指标。新训练与审计尚未完成，当前新完整报告明确拒绝发布。以下原版XGBoost来源条目仅解释2026-11-10历史报告，其余九模型规则不变。

## 来源与迁移

配置为 `configs/benchmarks/FLftv4_3407/reports/summary_22.yaml`，显式绑定当前Base22任务及 `data/3407`，并以SHA固定两个已批准的来源审计文件及目录上移映射。审计文件是原生预处理、环境、scaler与资产已通过审查的证据；报告不会重新执行各模型原生预处理或模型加载。审计SHA、原训练身份或当前源文件不一致均失败，不能通过修改审计标签直接复用历史预测。

每个模型×任务只选一个完整审计组，共250组。10项变化实验使用 `flft_v4_3407_22_retrain`，除ILBERT位于模型根外，其余位于 `retrain_22/<model>/`。其余12实验及三模拟：MLP、XGBoost、标准化ILBERT使用 `flft_v4_3407_22_completion`，其余七模型使用审计通过的 `catalog_v4_3407` 原身份。不得按性能或根summary选择来源。

用户已确认清理45个旧任务目录，并将本轮completion产物上移至 `outputs/benchmarks/FLftv4_3407/<model>/`。sweep配置/汇总/调度记录保留在 `sweeps/completion_22/<model>/`，独立缓存位于 `cache/completion_22/`，两套根记录不覆盖。已确认的旧 `outputs/benchmarks/v4_3407/` 前缀迁移及逐文件completion上移映射仅用于定位文件，原身份不改写。报告逐项重新核对原训练身份、模型配方、训练seed、当前registry科学字段、按顺序的训练/验证来源SHA、冻结配置、权重清单及完整预测行集合。MLP/XGBoost必须匹配当前特征schema，ILBERT必须为 `train_only_zscore`。

## 评估与指标

- 实验验证：22任务×十模型×五折，逐折从原单位预测重算MAE、RMSE、R²、NMAE、NRMSE；任务内折均值及折间样本标准差，随后任务等权。R²在常量目标时留空，不把未定义值替成0。
- 实验测试：仅纳入实际有完整测试行的任务。必须与五个验证折使用同一组训练身份，逐行核对五模型原单位预测均值；无测试集任务保留明确清单，不以验证结果填充。
- 验证共同尺度为该折其余四折完整训练行目标总体标准差；测试取五个训练尺度的算术平均。保留重复记录，不按模型训练过滤缩减共同总体；零方差尺度为1。此口径与ADR-0103共同尺度报告一致。
- 热膨胀、HOMO、LUMO按原训练集总体标准差归一化；独立发布验证/测试任务指标和三任务等权汇总。不进入实验宏平均、实验wins或实验排名。
- 同一任务按MAE给出竞争排名，相同MAE并列第一；总体按宏平均NMAE排序，同时报告平均排名与第一名任务数。折间标准差不解释为独立种子稳定性或统计显著性。

## 发布与身份

扩展现有 `scripts/benchmarks/summarize.py --baseline-config ... --output ...`，与旧 `--input` 模式互斥。报告仅写新输出，全部核验完成后再原子发布，失败不得留下半份正式报告；输出不得包含输入或被输入包含。新比较身份绑定22任务registry、完整当前数据来源、共同尺度和来源清单身份。

`source_manifest.json`保留每个任务组的当前路径、原始训练路径与完整训练身份、评估身份和逐文件大小/SHA；`summary.json`给出比较身份、覆盖和四个独立榜单。CSV保留逐折来源路径，`manifest.json`覆盖报告文件。旧根summary不拼入榜单，不改写成22任务身份。后续ILUME比较仍需单独适配，并核对现役Stage3来源；本报告不宣称已完成模型对比。

运行命令及审计限制见[完整baseline报告手册](../baseline-22-summary-runbook.md)。

## 验证

使用临时小数据覆盖多协议来源、三模型（含AIonopedia专用训练身份）、路径迁移、五折及三模拟、无测试集、重复行、缺失权重/折、SHA或审计篡改、集成错误、跨协议拒绝和输出原子性。执行专项及全量pytest、相关入口帮助、编译、文档链接和diff检查。正式报告只读取现有产物，不执行推理或重新评估。
