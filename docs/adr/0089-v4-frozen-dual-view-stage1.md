# ADR-0089: v4 frozen dual-view Stage1 and decoupled HoME learning

## Status

Accepted. Replaces ADR-0039/0082 only for the new `configs/v4/` mainline representation and Stage1 freeze boundary. v3, legacy and Capacity artifacts/configuration retain their original contracts; no migration or relabeling.

Encoder capacity is subsequently revised by [ADR-0090](0090-stage1-v4-residual-encoder-capacity.md): twelve SMILES layers and eight independent residual graph blocks. Its architecture-only revision reuses the existing v4 corpus/statistics/teacher cache; all other decisions below remain intact.

[ADR-0091](0091-stage1-v4-loss-weights-gradient-audit.md) subsequently changes the active RDKit/Uni-Mol coefficients to0.5/0.25 and adds read-only gradient audit. The original coefficient table below is historical in those two entries; objectives and normalization remain unchanged.

## Context

Stage1 should learn task-agnostic molecular structure; Stage2/3 should optimize multitask HoME without changing the Stage1 encoders. This is a complete recipe comparison, not a single-mechanism attribution: architecture, auxiliary supervision, ten-epoch budget and permanent freezing change together.

## Decision

- Stage1 encodes SMILES CLS and mean graph atom states independently (512D each), without role or descriptor input. Its residual MLP is `LN(x + Linear1024(GELU(Linear1024(x))))`; learned output is 1024D, atom states 512D. No token fusion, cross-attention, fingerprint or experts.
- Structural SMILES/atom/bond reconstruction each has coefficient 1. Alignment uses independent `512→512→256` projectors and `256→128→256` predictors (hidden LayerNorm/GELU), symmetric negative cosine with the opposite projection detached; no negatives or EMA. RDKit217 MSE, Uni-Mol768 cosine and masked 13-target electronic SmoothL1 are auxiliary-only; coefficients alignment/RDKit/3D/electronic are `0.1/1/0.1/0.1`.
- Each objective first averages valid elements/targets within a molecule, then computes `sum(role_weight * molecule_loss) / sum(valid_role_weight)`. Roles cation/anion/neutral have **loss weights 2/2/1**, not sampling probabilities. Missing objectives return differentiable zero; DDP sums valid denominators globally and compensates the gradient average.
- Preserve the existing full-corpus epoch shuffle and members/QC/splits. No role balancing, repeats or property loaders. Fusion alone has 80/10/10 both/SMILES-only/graph-only dropout; local structural/alignment states still compute both encoders.
- Stage1 runs ten fixed epochs, global batch128, AdamW1e-4/WD0.01, 5% warmup/current cosine, BF16, clip1, full-epoch resume. Training checkpoints retain disposable heads; `stage1_encoder.pt` exports only two encoders and fusion, final-state hash and source identity.
- Electronic targets are exact canonical-SMILES joins to simulation **train only**: HOMO/LUMO PBE/TZVP plus eleven HF targets. Statistics use matched unique Stage1 training structures only. No simulation valid/test labels and no augmentation-seed label propagation. RDKit statistics also fit only Stage1 train.
- Uni-Mol2 84M is offline-only in an isolated `unimol_tools==0.1.3.post1` environment. A local `modelzoo/84M/checkpoint.pt` is mandatory; no implicit downloads. Attempt every unique canonical structure from the full corpus, deterministic seed-derived ETKDGv3, MMFF else UFF; unavailable force-field parameters are an audited failure. Preserve charges/stereochemistry. Unsupported/failed molecules retain all other supervision and mask 3D; never substitute 2D/zero coordinates or crop atoms. Failures, source checkpoint SHA, teacher/RDKit version, corpus identity, sorted structure index and shard hashes are audited. Shards resume strictly; a separate `--limit/--output` audit reports throughput, success and storage before full generation. Partial audits cannot train Stage1.
- Teacher `--workers` is execution-only (default 1): a bounded spawn CPU pool prepares conformers/features in sorted order while only the parent owns GPU inference. Featurization is performed once. It does not change the cache recipe, per-molecule seed, batch boundaries, failure masks or shard resume contract. Non-TTY runs flush progress JSON during processing and shard commits; an existing cache root must have only one writer.
- Downstream concatenate frozen learned1024 with standardized RDKit217, producing1241. ObjectEncoder alone owns `Linear1241→1024 + LayerNorm`, then its existing1024D transformer/HoME interface. Default old input1024 creates no projection and consumes no additional RNG. Stage1 remains eval, gradient-free and outside optimizers throughout Stage2/3.
- Stage2 prepare caches frozen entity/atom tensors, bound to the original encoder hash. Nine-task physics-only HoME still uses logical/micro batch256, ten fixed epochs and LR3e-5 for ObjectEncoder including entry projection. Partial-charge uses frozen512 atom states and1024 context. Transfer GLOBAL and matched thermophysical/solvation GROUP with strict state/owner/shape hashes.
- Stage3 saves frozen1241 entity slots; only ObjectEncoder adapts in Phase1 at1.5e-5 for15epochs, then freezes and materializes a final-state-bound representation cache. All current experimental/private recipes, twenty-task authority (including hydration), five simulation auxiliary scopes in Phase2/3, raw exposure, `weighted_owner_raw_v1`, clipping, branch anchors, stitch and reporting-only validation remain intact; no PCGrad.
- Version-isolated core ablations: w/o Stage1 uses fixed-seed random frozen same architecture plus explicit descriptors; w/o Stage2 uses paired zero-update ObjectEncoder and twenty experimental tasks; w/o Stage3-HoME uses the formal prepared frozen representation and existing final-epoch single-task MLP. The latter two also omit simulation auxiliary training, so they are not pure routing/weight effects.
- v4 corpus/training/encoder formats and cache identity are independent; Stage2 final/encoder kinds and format4 are separate. Stage3 prepared kind/format4, final/delta/full kind/format4, resolved-plan11 and training contract15 reject v3 cross-resume. The single-task MLP retains its registered training backend/recipe but uses v4 checkpoint kind/format and state namespace when its authority is v4. Old paths and default behavior remain unchanged.

## Consequences and verification

New v4 Stage1, teacher cache, Stage2 and Stage3 outputs are needed; source data and splits can be reused, not old prepared/checkpoints. Baseline code is unchanged; reuse requires compatible comparison identities. This implementation does not download weights, generate the formal cache or run formal training/evaluation. Real teacher GPU compatibility and small-sample success/throughput are prerequisites for user-run full generation; contract tests use an explicitly injected fake teacher, not a scientific substitute.

Regression tests cover descriptor/role-independent encoding, molecule-weighted/DDP losses, missing labels, fusion dropout, cached teacher failures/integrity, final export/epoch resume, permanently frozen Stage1, trainable ObjectEncoder projection, nine-task inference including partial charge, source/Stage3 final loading and old-contract regression. Commands and environment separation are in the [v4 runbook](../v4-runbook.md).
